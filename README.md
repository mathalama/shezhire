# Shezhire (Шежіре) — Digital Family Memory Demo

Веб-приложение, демонстрирующее философию живой казахской генеалогии (*шежіре*). Создано для защиты философского проекта об исторической памяти, устной традиции и этике цифровой идентичности.

> **Target architecture: React → Go API → PostgreSQL. In the demo, data is loaded from a JSON file.**

---

## Ключевые принципы системы

1. **История не бывает анонимной:** Каждое воспоминание неразрывно связано с тем, **кто его рассказал**, через какой источник (устное предание или письменная семейная тетрадь) и в каком году.
2. **Равноправие спорных версий:** Когда родственники помнят события по-разному (например, пути перекочевки Бекжана или зимовку Ермека), обе версии хранятся рядом. Система принципиально не выбирает «каноническую».
3. **Естественность пробелов:** Забытые имена предков отображаются с достоинством, как естественные паузы устной памяти, а не как «ошибки» или «недостающие данные». Родовая связь продолжается через пробел.
4. **Защита живущих родственников:** Ныне живущие родственники по умолчанию скрыты; их имена и истории открываются только по осознанному согласию (для демонстрации предусмотрен переключатель симуляции).
5. **Этическая позиция:** В интерфейсе намеренно отсутствуют рейтинги родов/жузов, процентные доли происхождения, сравнительные диаграммы и соревновательные элементы.

## Архитектура и визуальные улучшения

- **Оптимизация под проектор:** Узлы компактны (175×64px), шрифт имён 16px bold serif с высоким контрастом, толщина соединительных линий 2.5px.
- **Полноэкранные полосы поколений:** Горизонтальные подложки на всю ширину канваса синхронизированы с рядами узлов (1-ші ата Түп ата ~1820-е гг. ... 7-ші ата Балалар ~2000-е гг.).
- **Исторические эпохи:** Каждый предок и поколение снабжены временным контекстом (~1820-е, ~1850-е, ~1910-е и т.д.).
- **Географическая связность:** Род зафиксирован в историческом ареале Сарыарки и Прииртышья (Карагандинская область / Каркаралы, Павлодарская область / Баянаул, Акмолинская область / Ишим).
- **Многоязычность (RU / KZ / EN):** Переключатель языка в шапке (Русский, Қазақша, English).

## Как запустить

### Требования
- Node.js (версия 18 или выше)
- npm (версия 9 или выше)

### Установка и запуск
```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.

### Сборка в production
```bash
npm run build
npm run preview
```

## Модель данных (`src/types.ts`)

```typescript
type SourceKind = "oral" | "written";

interface Version {
  id: string;
  text: string;
  place: string;
  teller: string;        // кто рассказал, напр. "Дедушка Нурлан"
  kind: SourceKind;
  year: number;          // год рассказа / фиксации
  recordedBy?: string;   // кто записал, если отличается от рассказчика
}

interface Person {
  id: string;
  name: string;          // "Unknown" для неизвестных предков
  generation: number;    // 1 (старшее) .. 7 (младшее)
  era?: string;          // примерная эпоха, напр. "~1820-е гг."
  fatherId: string | null;
  isLiving: boolean;
  consentToShow: boolean;
  isUnknown: boolean;
  versions: Version[];   // список версий (пустой у неизвестного предка)
}
```

## Сценарий демонстрации на защите (2 минуты)

1. **Общий вид дерева:** Откройте приложение — на экране крупное дерево из 7 поколений (Төлеген в Gen 1 ... потомки в Gen 7) на горизонтальных полосах-подложках с эпохами (~1820-е по 2000-е).
2. **Төлеген (1-е поколение):** Нажмите на узел Төлегена. В правой карточке видна история каменного зимовья и блок: *«Рассказал(а): Дедушка Нурлан · Запись · 2021»* и *«Записал(а): его внук Данияр»*.
3. **Две версии у Бекжана и Ермека:** Нажмите на Бекжана (Gen 5) или Ермека (Gen 4). Переключайтесь между версиями рассказчиков: место, год и источник меняются, а под ними видна нейтральная этическая сноска.
4. **Неизвестный предок (5-е поколение):** Нажмите на узел с пунктирной рамкой *«Имя не сохранилось»*. Спокойное философское объяснение непрерывности рода. Ветки продолжаются к Кайрату (Gen 6) и Тимуру (Gen 7).
5. **Приватность живущих (7-е поколение):** Арман и Алия скрыты замочком с надписью *«Живущий родственник · скрыто»*. Включите тумблер *«Согласие дано (симуляция)»* — их карточки и имена становятся видимыми.
6. **Фиксация устной памяти:** Нажмите кнопку *«Записать рассказ старейшины»*. Поле «КТО рассказал» обязательно — пока оно пусто, кнопка заблокирована с предупреждением: *«История без рассказчика не сохраняется»*.
7. **Языки:** Переключайте `РУС / ҚАЗ / ENG` в шапке в один клик.
